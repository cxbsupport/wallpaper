# Wallpaper

Papéis de parede distribuídos pelo Panda.

## Arquivos

| Arquivo | Uso | Resolução | Link direto (raw) |
|---|---|---|---|
| `comexi-fachada.jpg` | Corporativo (Comexi) | 3264x2277 | https://raw.githubusercontent.com/cxbsupport/wallpaper/main/comexi-fachada.jpg |
| `claudemir.jpg` | Claudemir | 1627x868 | https://raw.githubusercontent.com/cxbsupport/wallpaper/main/claudemir.jpg |

Use o link direto (raw) no Panda.

## Como trocar um wallpaper

Substitua o arquivo por uma nova imagem com **o mesmo nome**. Assim o link continua igual e não é preciso mudar nada no Panda.
