# Wallpaper

Papel de parede corporativo da Comexi, distribuído pelo Panda.

## Arquivo

| Arquivo | Resolução | Link direto (raw) |
|---|---|---|
| `comexi-fachada.jpg` | 3264x2277 | https://raw.githubusercontent.com/cxbsupport/wallpaper/main/comexi-fachada.jpg |

Use o link direto (raw) no Panda.

## Como trocar o wallpaper

Substitua `comexi-fachada.jpg` por uma nova imagem com **o mesmo nome**. Assim o link continua igual e não é preciso mudar nada no Panda.
